# Changelog

## 0.1.0 — Initial release

- Mix REAPER projects through natural-language conversation in the local WebUI or QQ/NapCat.
- Inspect tracks and loudness, adjust levels and effects, and render audio for listening.
- Use listener feedback and saved preferences to guide the next mix.
- Configure model providers and API keys in DeepSeek Harness Settings → Models.
- Extend mixing knowledge with Markdown knowledge packs; an original example pack is included.
- Set up local paths and the REAPER bridge through the first-run wizard.

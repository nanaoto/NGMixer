# NGMixer public mixing core

An example mixing knowledge pack included with NGMixer. The notes are written for this project and licensed under the repository's [MIT license](../../LICENSE).

The [manifest](./manifest.json) lists each note's title, tags, and source. The mixing planner and `mixing_knowledge` tool search these notes for advice relevant to the current request.

To add your own notes, create a separate pack and register it in [knowledge/catalog.json](../catalog.json). See the [setup instructions](../../README.en.md#build-a-mixing-knowledge-library-from-your-material) for the format and size limits.

# Metering and Reference Comparison

Meters establish reproducible context; audition establishes musical value.

- Capture peak, RMS, integrated loudness, and loudness range over a representative region.
- Compare candidates at controlled perceived loudness so level does not masquerade as quality.
- Interpret silence, short events, fades, and sparse arrangements before treating a number as anomalous.
- Evaluate both the target track and the mix consequence. A local level improvement can create masking or overload downstream.
- Preserve headroom through intermediate stages and verify the final delivery format separately.

Reference material is useful when level matched and relevant to genre, arrangement, and delivery medium. Use it to calibrate a dimension, not to force a single universal target.

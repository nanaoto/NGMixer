# Dynamics and Envelope Shaping

Dynamics processing changes both level distribution and musical motion.

- Identify the intended outcome: control peaks, stabilize audibility, add density, reshape attack, or create movement.
- Relate attack and release to the source envelope and rhythmic context; verify pumping and transient loss in the mix.
- Use gain reduction as an observation, not as a quality score.
- Compare compression against gain or automation when the goal is audibility rather than envelope change.
- Preserve the requested impact, breath, and articulation as named constraints.

Serial, parallel, and sidechain processing solve different control problems. Select a topology deliberately and record the path so later feedback can be attributed to the mechanism used.

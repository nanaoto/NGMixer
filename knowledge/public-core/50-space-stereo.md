# Space, Depth, and Stereo Translation

Depth and width emerge from level, spectrum, timing, ambience, and arrangement.

- Distinguish direct-signal changes from send/return changes before editing.
- Use pre-delay, early reflections, decay, filtering, and automation to shape distance without obscuring articulation.
- Check mono compatibility and correlation after width changes.
- Protect the center image and low-frequency stability unless the request explicitly changes them.
- Audition transitions and section boundaries; a static space setting may not serve the whole arrangement.

When a user asks for a wider chorus, candidate mechanisms may include arrangement-aware panning, send automation, decorrelated ambience, or selective mid/side balance. Choose the smallest mechanism that preserves vocal focus and translation.

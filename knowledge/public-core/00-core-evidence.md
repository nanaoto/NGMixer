# Evidence-Driven Mixing Loop

Use a repeatable observation–action–audition cycle.

- Read the current project before proposing changes. Treat track identity, routing, plug-in instances, and measured audio as current facts.
- Translate the user request into a perceptual goal and explicit preservation constraints.
- Prefer the smallest reversible intervention that can distinguish the leading hypothesis from alternatives.
- Record actual before/after values from the execution receipt.
- Render a content-addressed audition and attach feedback to that exact artifact and project version.
- Accept, revise, or roll back from evidence. Do not infer success from a valid tool call alone.

Separate deterministic observations from aesthetic hypotheses. Peak, RMS, LUFS, topology, and parameter identity can be measured; “intimate,” “wide,” and “aggressive” must be validated by listening in context.
